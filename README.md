# Student Registration Form

## About the Project

This project is a student registration form built using HTML and CSS.

## Features

* Collects the student's full name.
* Collects the student's email address.
* Collects the student's phone number.
* Allows the student to select gender.
* Allows the student to choose a course.
* Includes a Register button.

## Technologies Used

* HTML5
* CSS3

## Project Files

* `index.html` — contains the registration form structure.
* `style.css` — contains the styling for the form.

## How to Run

Open `index.html` in a web browser to view the registration form.
